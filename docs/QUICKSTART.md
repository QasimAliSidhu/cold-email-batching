# Try Cold Email Batching

## Start here

Clone this repository and open a terminal in its root. All examples below use fictional inputs.

The CSV preview uses the Python standard library and blocks SMTP and credentials. The optional sample UI requires Flask; see [its README](../examples/review_ui/README.md).

```console
python examples/preview_demo.py
```

## A useful exercise

Run the offline CSV preview, then open examples/review_ui. Edit Alex's note and switch to Harbor to compare the generated greeting, company subject and body. Sending is unavailable in the sample UI.
